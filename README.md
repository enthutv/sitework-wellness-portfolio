# Sitework Wellness Store

A frontend-only interactive showcase of an AI operations team. Open the dashboard to watch work move from customer inquiries through order processing, payments, delivery, and reporting.

The eight roles are AI CEO, Executive Secretary, Sales & Customer Support, Order Processing, Inventory, Fulfillment & Delivery, Finance, and Quality & Compliance.

Activity is saved in this browser using IndexedDB. The showcase uses generated business scenarios and does not process real customers, payments, or orders.

Serve the repository root with a static web server. The built pages and assets are already included.
